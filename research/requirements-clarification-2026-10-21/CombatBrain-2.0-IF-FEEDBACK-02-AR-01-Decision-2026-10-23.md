## 1. 用户裁决与确切范围

助手在解释三种方案及反例后，提出本轮签收范围：

> 任务反馈、环境知识与本场失败记忆采用不同的有效性规则。更换计划本身既不能恢复旧任务或旧授权的控制效力，也不能清除相同条件下仍相关的失败证据；条件变化、信息过期或来源失效时，应重新核验其适用性。失败记忆仅作为决策依据，不自行取消任务、解除职责或扩大权限。

对应提问为“你是否认可方案 C 的这一原则？具体身份、版本、时序和重试规则仍保持 OPEN。”

用户明确答复：**“认可”**。因此确认上述原则，不将其解释为采纳整个 Astra 原型、全部建议卡或具体消息实现。

## 2. 已确认的信息有效性原则

| 用途 | 例子 | 有效性边界 |
|---|---|---|
| 当前任务反馈 | 此次绕行受阻、当前安全动作正在执行 | 原任务被替换、相关身份或权限失效后，不得继续更新新任务或恢复旧行动。仅修改全局 Plan 编号、实际任务未变时，不应一概清空。具体派发身份合同留待 AR-02。 |
| 环境知识 | 通道被堵、敌方枪兵正在掩护弓兵 | 按对象、位置、条件和新鲜度重新判断。旧任务结束不证明环境已改变；旧观察也不能无限冒充当前事实。 |
| 本场失败记忆 | 在这些条件下，试探没有诱发回援 | 保存失败条件和证据，供后续评价及抑制重复尝试；不能靠换 Plan ID 清洗，也不能把一次失败推广为永久不可能。 |

三类用途不要求三套独立任务状态机或消息服务。继续遵守 IF-FEEDBACK-01 的单一任务生命周期权威、Formation 观察/推断与 Commander 裁决分离。

补充边界随本轮讨论确认：

- 真实条件变化后允许重评失败的适用性；失败记忆不成为永久否决。
- 时间过去可以使证据变旧、产生重新核验的需要，但不能单独证明机会恢复。
- 玩家收回 F6 后，旧任务与安全命令必须失去控制效力；来源可信、仍相关的环境知识可保留。重新授权仍须验证当前权限和局势。
- 失败必须说明哪个预期效果没有兑现。突破受阻不自动否定仍然有效的牵制、掩护或其他关键职责。
- 本场记忆不扩大写令权限、取消任务权或职责解除权，也不新增跨战斗学习范围。

## 3. 证据与设计反例检查

已有研究证据：[第二阶段独立复查 R1](../astra-research-2026-10-22/independent-review-phase2/CombatBrain_Phase2_Independent_Review_2026-10-22.md)、[探针源码](../astra-research-2026-10-22/independent-review-phase2/probe_contract_gaps.py)及[原输出](../astra-research-2026-10-22/independent-review-phase2/contract_gap_results.json)。R1 指向修订 baseline 的 Runtime 路径：probe 未获响应后换成 hold，其他相关条件未变时失败集合消失、probe 重现。它是研究原型反例，不是生产 CB2 故障或实战收益结论。本轮未重新执行这些脚本。

以下为本轮**纸面反例检查与设计要求**，不是自动测试或游戏 PASS：

| ID | 反例 | 方案 C 必须保持的语义 |
|---|---|---|
| AR01-1 | 原任务被替换后，旧受阻报告延迟到达 | 不更新新任务、不恢复旧控制效力；保留历史不等于承认其当前有效。 |
| AR01-2 | probe → hold → probe，相关条件未变 | 换计划本身不清除仍适用的失败证据。 |
| AR01-3 | Plan 编号不变，但任务实际目标或相关身份已变 | 不能仅凭相同 Plan 编号继续认定旧反馈适用。具体核验字段 OPEN。 |
| AR01-4 | 仅修补其他编队任务，本任务实际未变 | 不因全局 Plan 编号变化一概清空仍有效反馈；派发作用域由 AR-02 继续裁决。 |
| AR01-5 | 敌方掩护撤走或我方获得支援 | 重新评价原失败条件，不把历史失败变为永久禁令。 |
| AR01-6 | F6 收回后重新授权 | 旧命令不得重放；可用知识与当前控制权分别核验，不能靠重新授权洗掉仍相关经验。 |
| AR01-7 | Formation 槽位复用、拆并或对象更换 | 旧对象反馈与失败关系不得自动套用新对象；相关环境知识也须重验适用范围。 |
| AR01-8 | 突破受阻，但仍有效牵制 | 记录未兑现的具体效果，不自行宣布全部职责失效或自由后撤。 |
| AR01-9 | 时间过去且没有新鲜观察 | 标明时效/不确定性并重新核验；不自动视为机会恢复或永久受阻。 |

设计层结论：在上述边界下，分语义有效性与已签收的 Commander 唯一裁决、F6 权限、职责连续及 IF-FEEDBACK-01 架构一致。具体实现是否满足仍须后续接口、调用链与引擎证据验证。
