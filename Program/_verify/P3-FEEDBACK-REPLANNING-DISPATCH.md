## 3. 实现前钉死的结果口径与评价

以下是**本次新提出的限定 P3 设计**，不是已有实现或已验证战术常量。目的为收敛可观测的收益/代价与决策，影响只限本单必要字段和行为；不改变架构边界。下发本单后作为首版实现合同，真实效果仍待验收。未经设计复核不能在失败场后改阈值、分母或基线迎合通过。

### 3.1 行动、观察对象与基线

采用 P2 的远程优势三职责作为初始行动；仍先建立保护/辅助关系，才允许主力有限接近。Plan 创建时记录预期：通过有限接近和原生正常交战削弱最近敌步兵局部，同时将己方累计损失控制在 5%以内。只陈述预期，不预记成功。

观察对象从实际敌方 Infantry 中，按主力实际质心距离选最近一支，距离相同按 Team/Formation 槽位及对象身份稳定排序；必须≥20名有效非坐骑成员。目的仅是确定观察局部，**不是给单兵指定攻击目标**。没有此对象则本单正例前置未满足，不能把全军减员换作局部战果。

`t0` 为该行动首次主力推进普通命令真正写入的 Mission 时刻，写入前同主线程采样并冻结：该敌 Formation 的有效成员集合 `E0`、本方整队有效非坐骑成员集合 `F0`、三职责对象/人数/位置、目标/身份及先前独立样本。未写令、未实际正常交战或发生在 t0 前的损失不算行动结果。分母分别 `NE=|E0|≥20`、`NF=|F0|>0`；不得在每次决策、Plan更换、转编或增援时重置。

成员身份至少绑定 Mission + Agent.Index + 当次对象身份，保留初始队伍/编队。追踪集合成员此后在任何 Formation 的状态；转编、分离、骑乘变化、索引复用不当死亡。Kills/Unconscious 是伤亡；Routed 单列为战力脱离，本版不并入伤亡分；Deleted/None、缺记录、异常读取、身份疑似复用属于未知，不把“未看到”当死亡。已直接观察并归档的 Killed/Unconscious 可保留终态事实。不得改 Agent 状态。

完整性须逐样本声明；有无法解释的基线成员未知、重复身份、Mission变化、终态采样丢失则本窗口不可判正负。正例还须确认 E0 当前幸存成员主要仍在同一局部：当前原目标对象存在、≥6名活跃 E0 成员、没有显著转编/分散形成另一个方向；否则只记原对象减员，不推断此处可利用。增援不计新分母，但当前目标的实际全部有效人数与邻近反制力量必须进入风险门，不能把“旧人损失”当成“新力量不存在”。

### 3.2 量纲、公式、阈值和适用限度

时间均为 Mission 秒；距离为米；人数为非坐骑有效成员个数。只将无量纲比率放入共同评价。

- `DE(t)` / `DF(t)`：从 E0 / F0 中直接确认在 t0 后 Killed 或 Unconscious 的成员数（每身份只计一次）。`LE=DE/NE`，`LF=DF/NF`，范围 [0,1]。名称“伤亡”在本单只指此口径，不包括转编、逃跑、增援差或医学伤害。
- `rf=(DF(t)-DF(s))/(NF*(t-s))`，单位 s⁻¹；s 是同一行动内距t至少12s的最近有效评价样本（正常3s节奏约12–15s），记录实际跨度。没有该样本则速率未知，不能补零。`H=12s`，`H*rf` 是近段速率延续12s的代价代理，不是预测伤亡事实。
- `B=clamp(LE/0.20,0,1)`：敌局部伤亡收益代理；20%局部损失记满尺度，不等于20%胜率。
- `C=clamp(max(LF,H*rf)/0.10,0,1)`：己方累计/近期损耗代价；整队10%损失或相同12s代价记满尺度。
- `U=0.5*B+0.5*(1-C)`，范围 [0,1]。收益与保全同权进入同一评价，未归一化的人数和秒数不得直接相加。20%局部与10%整队是本单试行尺度，体现更保守的整队控损，不宣称 Charter §18 已由“0.5”证明合理。

先做资格/执行/数据完整性门，再比较下表。同一评价点冲突时，安全失败 > 高损失止损 > 正反馈 > 继续；不能用敌方高损失掩盖己方高损失。

| 决定 | 同一输入的条件 | 后续生产行为 |
|---|---|---|
| 正反馈追加 | t−t0≥12s，LE≥0.15，LF≤0.05，H*rf≤0.05，U≥0.60；目标仍有局部价值，P2三职责与实际当前兵力继续线成立，无新反制力量堵住推进 | 连续两个3s评价点成立且满足8s稳定时间，追加一次有限协同推进的新Plan；不能直接跳过依赖或仅重复旧Move |
| 高损失止损 | LF≥0.10 或 H*rf≥0.10；前者无需等待速率窗口成熟 | 第一个满足条件的高层评价点即决定终止旧攻势并调整，允许打破8s稳定时间；必须记录安全优先的例外原因 |
| 无收益且有代价 | t−t0≥24s、LE<0.05、LF≥0.05、U<0.40，连续两个评价点成立 | 调整撤回；不能把有效Move当作值得继续的理由 |
| 继续观察/执行 | 未满足上列；无硬失败且原计划仍有效 | 沿用当前Plan，不重发已写普通命令；记录未成熟窗口/中性/收益与代价数值及下一次评价时间，不自动恢复静态，也不伪造收益 |

“无新反制力量堵住推进”采用可复算的 Formation 级边界：以拟新增主力目标点为中心、半径30m内，统计所有敌方非坐骑有效人数；若其多于本方三职责当前有效人数总和，或任何职责低于P2人数继续线，不追加。用成员实际质心定义Formation是否落入半径，不冒充逐兵空间密度/真实火力覆盖。等于允许；中心未知、目标无幸存成员/有不可解释转编则不追加，并说明原因。当前远程优势继续线及全队兵力线仍生效。

该风险门只是本单粗略边界，不能证明射程、掩体、路径可达或敌方战力。现场发现“数值正但实际前进明显不合理”，拒收该正例并交回具体矛盾；不能因此扩大地形系统或强行合入观测V1。必要尺度调整须更新派单版本和登记，重取受影响证据。

### 3.3 节奏、延迟与稳定性

复用 `DecisionCadenceSeconds=3.0`、`PlanMinStableSeconds=8.0`、新分配首普通令≥1.5s、全体相邻普通实写≥1.5s、快照最大年龄2s、命令效果窗口3s、P2关系建立窗口20s。命令生效的3s和战果的≥12s是不同窗口；不能因3s内零杀伤取消正常行动，也不能延长既有命令生效截止掩盖卡住。

正反馈/低收益变更需连续两个有效评价点；未知点中断连续成立，不用旧数值补齐。微小变化不更换Plan。对同一 t0 只允许一次正反馈追加；继任Plan继承E0/F0/t0和累计损失，不能凭同一份旧战果每3s无限加码。追加后继续评价与止损；本单不再开第二条追击链。已有控制权、命令覆盖、Mission、成员位置/依赖安全处置逐tick检查，关闭/清槽/撤权预算仍≤1s，不受3s/8s拖延。

高损失发生到高层决定≤3s+一个实际Mission tick；已决定后关闭、清槽、撤权及退出尝试≤1s。给出实际采样间隔/tick及时间表；严重卡顿不能靠“多给一个tick”无限豁免。rf触发时间按实际有效窗口计算，不能倒推到任意伤亡瞬间。

## 4. 后续行动、Plan身份与旧命令收尾

正反馈不是固定计时触发：新Plan有新PlanId，明确继承旧PlanId、触发输入/反馈时刻、t0及冻结集合、理由与U/B/C。保留三职责，用当前实际质心和敌目标方向重新计算几何；新增主力接近量复用 `min(25m,当前距离/4)`。先重新安排保护/辅助、主力Hold，再在新关系真实成立后放行新推进。增加投入指追加这轮实际协同任务，不要求新兵种/第四Formation。新任务有独立ID、版本、依赖和1.5s传导；不能沿用旧有效目标或Ready。新位置命令必须再次通过现有世界位置/读回/效果门；这不是路径可达性保证。

负反馈优先结束攻势；仍有资格、有效中心与非零敌我方向时，新Plan仅尝试有限撤回：每个原受控且仍合法的对象，以自己当前实际质心沿背离当前敌队有效质心方向移动20m，使用现有Reposition；不发Charge，不要求新的协同推进关系。到各自目标5m内后转Hold（独立新任务），20s未到或命令3s效果失败，终止该撤回Plan并按已有退出路径如实处理，不循环重试、不压制原生抢回控制。方向/世界位置/资格不可用则只终止，不编造安全退路；该场不能冒充“已撤回”。成功负例至少证明攻势停止，可将撤回失败如实单列，不以反复失败持续进攻。

已知负反馈未消退时，不得让旧P2条件“仍有远程优势”在下一评价点重建同一攻势。维持撤回/保持或交回原生的明确状态；只有新的实际条件和重新核对的风险能进入后续计划。本单不要求实现全场战略切换，但至少有一场继任Plan实际完成追加或调整，纯终止不能替代全部重规划证据。

每次转换必须按下述可核对顺序：

1. 记录决定时刻、原输入/基线、预期与实际、四类决定、旧PlanId/Revision和原因；新Plan尚未成功生成时关联值显式为空，不能伪造新Plan。
2. 关闭旧Plan普通任务、未写提案、已公布候选、handoff待写槽，撤销旧权限；迟到回调/反馈只可归旧身份，不能清新槽、补权或再普通写令。进入新Plan前禁止两个普通写源并存。
3. 需要停止的仍合格对象走现有退出Hold/Stop通路；≤1s内记录每对象尝试、实际获选/实写/读回或未应用。撤权、清槽与“士兵已停止旧动作”分开。负例必须有独立实际订单/位移证明旧攻势停止；若退出未应用且仍执行旧推进，该项未通过，不能仅凭零旧WRITE宣称通过。
4. 旧退出确认后公布新分配，或将明确未完成对象保留为停止失败并不计成功调整。复用现有新分配归属隔离，迟到旧退出不能覆盖新计划。新普通令按新分配计延迟，退出动作保持原安全豁免。
